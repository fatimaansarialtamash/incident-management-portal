Incident Management Portal
A web-based Incident Management System developed using Python, Streamlit and SQLite.

Features:

Create Incidents
Search Incidents
Update Incident Status
Dashboard Metrics
Priority Filtering
Status Visualization
Created Date Tracking
Excel Report Export

Technologies Used:

Python
Streamlit
SQLite
Pandas
Plotly

Installation:

pip install -r requirements.txt

Run Application:

streamlit run app.py
